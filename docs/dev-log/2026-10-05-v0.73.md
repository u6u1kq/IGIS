# 2026-10-05 V0.73 MCP、对话列表、回退与记忆

在 V0.72 上追加。没有 git 提交，没有改 git 配置。没有新的几何引擎，没有新的 GPL/LGPL/AGPL 依赖。坐标和密钥不进模型、RAG、账本、空间审计、用户记忆、控制台或错误文字。地图、图层库、空间表单、GDL、RAG、PPT 页签、预制数据库、模型选择、齿轮和 `start-igis.cmd` 都保留。产品版本是 **0.73**，不是 7.3。

新依赖：官方 `@modelcontextprotocol/sdk` 1.18.2（MIT）和 `zod` 3.24.2（MIT），已写入 `config/licenses.lock.json`。

## MCP 服务器

- 模块名：`packages/mcp-server`（`src/stdio.ts`、`execute.ts`、`names.ts`、`external.ts`），`apps/cli/src/mcp-server.ts`，`apps/cli/src/gis-runtime.ts`。
- 变更内容：
  - 用官方 MCP TypeScript SDK 在 stdio 上暴露现有 GIS 工具：list/describe、buffer、intersect、clip、query、stats、style、visibility、order、zoom、export、gdl summary/run。
  - `tools/call` 走现有 `ToolAdapterPort` 执行器，不另写一套几何。MCP 名称把点换成下划线（如 `map.buffer` → `map_buffer`）。返回值与对话工具相同，是无坐标摘要。
  - `--help` / `--list-tools` / `--once` 不打开 GDAL。默认长驻 stdio。根目录 `npm run mcp`。
  - 齿轮可填可选外部 MCP 命令和参数（与其他设置一起存，日志不含密钥）。配置后 `POST /api/chat` 会把外部工具接到现有调度器（`map.ext_*`）。网页应用不依赖 Cursor。
- 接口契约变更：无新 HTTP 路径。CLI：`apps/cli/src/mcp-server.ts [--help|--list-tools|--once]`。
- 未解决问题：外部 MCP 进程若未启动或命令无效，该轮只是接不上额外工具，不会挡住本地 GIS 工具。没有对着真实第三方 MCP 服务做联调。

## 回退与用户记忆

- 模块名：`apps/cli/src/conversations.ts`，`apps/cli/src/user-memory.ts`，`packages/provenance/src/spatial-audit.ts`，`packages/llm-dispatch/src/gis-prompt.ts`，`loop.ts`。
- 变更内容：
  - 回退上一轮助手回复：从当前对话删掉该助手轮（及其前面的用户句），并只删除该轮记录的 `createdLayerIds`。空间审计写入 `operationType: "rollback"`，不含坐标。
  - 用户记忆存在 `var/memory`（被 `var/` gitignore 覆盖）。齿轮「记忆」可增删。含坐标、几何或密钥的文本会被拒绝。系统提示通过 `buildGisSystemPrompt` 注入有上限的无坐标摘要。
- 接口契约变更：
  - `POST /api/conversations/rollback` → `{ messages, removedLayerIds }`。
  - `GET /api/memory`，`POST /api/memory/add`，`POST /api/memory/delete`。
  - `runAssistantTurn` / `DispatchInput` 增加可选 `userMemory`。
  - 助手消息可带 `createdLayerIds`。
- 未解决问题：回退不会撤销该轮对已有图层做的样式/显隐/顺序改动，只删新建图层。
