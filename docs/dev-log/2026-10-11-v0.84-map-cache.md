# 2026-10-11 V0.84 地图与缓存

V0.83（commit 6a58a8a）之上。根因：实测发现地图"什么都不显示"不是渲染 bug——图层挂载正常，但相机从不对准新图层（默认中国全图 zoom 3.4，教学尺度的数据是亚像素）；且浏览器侧全部 no-store 零缓存。

## 模块名

`apps/desktop/ui/app.js`，`app.css`，`i18n.js`；`apps/cli/src/desktop-api.ts`，`map-http.ts`；`packages/surtgis/src/core/layer-store.ts`；`packages/spatial-ops/src/service.ts`；`packages/llm-dispatch/src/http.ts`；`packages/provenance/src/ambient.d.ts`；新增检查 `apps/cli/src/v084-map-cache-check.ts`。

## 变更内容

- **图层定位（根因修复）**：mountServerLayer 增加 fit 参数——用户动作（导入、GDL、地图面板分析、聊天结果、审计载入）挂载的新图层无条件对准（fitBounds, maxZoom 14）；多图层联合定位 fitToBoundsList（导入多文件一次对准全部）。旧规则（本回合未定位过才自动定位一次）保留给非用户动作路径。对话切换仍恢复该对话保存的视图（mapScopes 机制不变：每个对话有独立图层列表）。
- **缩放反馈**：缩放结束后在导航控件下方短暂显示"级别 12.3"徽章（900ms 淡出），覆盖 +/- 按钮与滚轮。i18n 双语键 map.zoomLevel。
- **框选视觉反馈**：框选拖动时在鼠标位置实时画半透明虚线矩形（igis-box 源 + fill/line 层，unproject 屏幕坐标转经纬度），松开清除；对话切换清除；restack 保持置顶。修复"框空气时看不到框在哪"。
- **上传警告措辞**：缺 .prj 的警告明确"已按未声明载入：空间分析不可用；属性查询、统计和显示可用"——不再像失败。
- **入库几何哈希**：LayerMeta 增加 geometryHash（64 位十六进制），loadFile/createLayer/derive 三处入库时算一次，meta.json 落盘、restore 读回校验；缓存键优先用入库哈希，旧图层无哈希时现算回退（值一致，零行为变化）。
- **HTTP 缓存**：图层 geojson 端点与 vendor 静态文件改 `Cache-Control: public, max-age=31536000, immutable`（layerId 不复用、图层文件入库后不变，强缓存安全）；UI 文件（app.js/app.css/i18n.js/index.html）改 ETag 协商缓存（mtimeMs+size，If-None-Match 回 304）。API 响应保持 no-store。
- **LLM 出站审计**：postLlmJson 出站前把消息体落盘 var/llm-requests（去查询串防密钥落盘、消息体 256KB 截断、保留最近 200 份、失败不阻塞调用）——补上数据敏感框架唯一没有事后核查能力的环节。
- ambient.d.ts：FileStat 增加 mtimeMs。
