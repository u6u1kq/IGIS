# V0.89.2 跟进记录

## 已完成

- 桌面 GIS runtime 接入本地 Python GDAL 进程桥，默认开启；设置「外部能力」可即时关闭或重新开启，并可选择 `IGIS_PYTHON` 指定解释器。
- GDAL 桥增加 osgeo/GDAL 启动自检，设置页显示状态。重投影遇到缺少源 CRS 时拒绝运行，并固定传统 GIS 轴序，避免错误转换或仅改写 CRS 标签。
- 图层库恢复旧元数据时，遇到 `invalid` / `wkt-no-epsg` 身份会重读已存 WKT；有效的无 EPSG 投影定义迁移为平面身份。
- 桌面上传把源文件放进当前对话工作区；上传、手动载入、地图空间分析和聊天工具创建的图层都记录归属，删除对话时清理对应文件和未被其他对话引用的图层。
- 地图接受文件拖放，自动上传、导入和调整视图。
- T5 已在现有工具循环中完成：失败以 code/message 结构化返回模型，同一工具、参数和失败原因重复两次后停止；`llm-dispatch` 自检覆盖此行为。
- T6 检查点在每条新指令执行前自动保存（最多保留 32 个/对话），持久化轮次边界、待澄清计划、最近创建图层和可重跑原指令；“更多 → 检查点重跑”按顺序回退后续轮次并复用现有图层、知识库、审计清理流程，完成后恢复计划状态并将原指令放回输入框供用户确认重跑。

## 实测限制与范围

- 使用当前桌面线程提供的 Python 运行时核验时，`from osgeo import gdal, osr, ogr` 报 `ModuleNotFoundError`。因此本轮没有声称 Python/osgeo 桥或「重投影→EPSG→叠加分析」真实链路通过；安装 GDAL Python bindings 后可用设置页自检，再执行教材实验 88。
- 对话范围覆盖桌面上传文件和桌面地图/聊天创建的图层；MCP 等不带对话上下文的入口仍是全局工作区，不属于任一对话。
- 长会话压缩没有直接引入对话摘要：模型请求由当前轮指令、有限地图摘要和显式用户记忆构成，不发送完整聊天记录；用户记忆本身限制为 20 条、摘要不超过 1600 字，因此当前架构不存在因完整聊天历史累积导致的上下文膨胀。
- T3 DEM 功能保持原有状态，本版只接通外部桥，不扩展 DEM 能力。
