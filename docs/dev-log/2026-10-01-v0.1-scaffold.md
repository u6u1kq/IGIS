# 2026-10-01 V0.1 骨架

本轮只建立目录、TypeScript 契约、锁文件和本日志。没有沙箱运行时，没有训练，没有 qgis-wasm，没有 wasm 二进制。未创建 git 提交。

## 仓库初始化

- 模块名：仓库
- 变更内容：在 `e:\ai工作区\Igis` 建立空 git 仓库，分支 `main`。自有代码许可证 Apache-2.0。`.gitignore` 排除密钥、用户数据、gdb、导出文件、wasm 和模型权重。
- 接口契约变更：无代码契约。新增 `LICENSE` 与 `THIRD_PARTY_NOTICES.md`。
- 未解决问题：当前环境没有可用的 `git.exe`，仓库目录是按 Git 空库结构写的。安装 Git for Windows 后可以正常使用。尚未配置提交者身份，也没有提交。TypeScript 没有写入项目依赖；契约已用一次性的 `tsc --noEmit` 检查通过。

## shared-types

- 模块名：`@igis/shared-types`
- 变更内容：定义数据面顺序、控制面顺序、内存引用、图层摘要、模型工具请求、内核 function call、沙箱策略、检索默认值和外部 LLM 配置。
- 接口契约变更：新增 `MemoryRef`、`LlmToolRequest`、`FunctionCall`、`ControlMessage`、`SandboxPolicy`、`DEFAULT_RETRIEVAL_CONFIG`、`EMPTY_LLM_CONFIG`。几何参数名在类型里被排除。
- 未解决问题：句柄的运行时校验还没有实现。字符串标量仍可能被调用方填入几何文本，类型系统挡的是参数名和结构。

## gis-kernel

- 模块名：`@igis/gis-kernel`
- 变更内容：定义可插拔后端 `GisBackendPlugin` 与 `GisKernel` 注册表。主接口只接受宽松许可证。
- 接口契约变更：新增 `register`、`unregister`、`get`、`list`、`execute`。
- 未解决问题：没有注册表实现，三个后端都还是空槽。

## memory-bus

- 模块名：`@igis/memory-bus`
- 变更内容：定义内存块存放、句柄解析和释放，以及把模型请求解析成内核调用的接口。
- 接口契约变更：新增 `MemoryBus`、`HandleResolver`。
- 未解决问题：没有进程内存储，也没有 Worker 转移实现。

## io-openfilegdb

- 模块名：`@igis/io-openfilegdb`
- 变更内容：定义 OpenFileGDB 只读打开、图层列举和读入内存引用。
- 接口契约变更：新增 `OpenFileGdbReader`、`OpenFileGdbSession`。会话类型没有写方法。打开标志固定为 `GDAL_OF_READONLY`。

## gdal-wasm-adapter

- 模块名：`@igis/gdal-wasm-adapter`

## duckdb-spatial

## surtgis

## rag-meta

- 模块名：`@igis/rag-meta`
- 变更内容：定义元数据文档、查询和存储接口。文档含图层名、字段名、坐标系、要素数量、可选范围和样式摘要。
