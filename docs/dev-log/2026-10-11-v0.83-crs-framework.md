# 2026-10-11 V0.83 CRS/单位框架收口

V0.82（commit 227da64）之上。本版本解决同一框架的六个问题：载入丢 CRS、空间运算只认 4326/3857、米制缓冲各向异性、缓冲圆形近似过粗、导出丢 crs 成员、降级无说明。

## 探测结论（v083-crs-probe）

1. `GDALGetProjectionRef` 对矢量数据集返回**空字符串**（即使有 .prj），不能用于图层 CRS。
2. `OGR_L_GetSpatialRef`/`OSRExportToWkt` 在 gdal-js@2.2.0 的 wasm 导出面里**不可 cwrap**——图层级 CRS 接口拿不到。
3. 因此 **Shapefile 的 CRS 只能从同名 .prj 直读**（与 read.ts 元数据路径的 applyShapefileCrs 同一模式）；GPKG 等其他格式当前读不到 CRS，降级为「未声明」并完整说明影响。
4. proj4@2.15 直接吃 WKT：4326↔UTM50N 环回误差 0.0000 米；`proj4.Proj(wkt)` 可读 `datumCode`/`datum_params`（WGS84 解析为零参数数组，北京54 无参数为 null，CGCS2000 datumCode=`china_2000`）。
5. **静默误差实证**：北京54（无 towgs84）与带 towgs84 的同一坐标变换到 4326 相差 **132.4 米**——严格拒绝不做近似变换的依据。
6. aeqd（正射等距方位）投影：纬度 40° 东西 0.01° 地面真值 852.8 米，aeqd 平面 853.9 米（误差 0.13%）。
7. **Turf 的 `units: "degrees"` 是球面语义，不是平面字面度**——在 aeqd 米平面上用 degrees 缓冲会得到完全错误的形状。最终方案：aeqd 米平面线性缩放成「伪度」平面（因子 = turf 的 meters→degrees 线性换算 8.9932e-6），turf 的 meters 换算在等距平面上各向同性，缓冲半径即地面真距离；缓冲后再缩回并逆变换。实测 40°N 东西向 100 米缓冲：E/W 99.86 米、N/S 100.09 米（误差 ≤0.14%；修复前 turf 度圆东西向约 230 米，差 23%）。

## 变更内容

- **载入读取 CRS**：vector-geojson 对 .shp 直读同名 .prj（形状校验后返回 WKT）；service.readWithGdal 从 WKT 提取 `AUTHORITY["EPSG",n]`（取最后一个）构成 known 身份并保存 crsWkt 到图层元数据（meta.json + 内存 + restore）。GeoJSON 路径不变（crs 成员）。
- **三种拒绝/降级各自独立说明**（EPSG-only，不兼容自定义投影）：
  - WKT 无 EPSG 代码 → invalid 身份，载入消息「没有标准 EPSG 代码…请转换为标准 EPSG 坐标系后重新导入」；
  - .shp 缺 .prj → 未声明 + 「空间分析不可用；属性查询、统计和显示可用；建议补齐 .prj」；
  - 非 shp 格式（如 GPKG）→ 未声明 + 「该文件格式的坐标系未能读取（当前只读 Shapefile 的 .prj）…建议转换为带 .prj 的 Shapefile 或带 crs 的 GeoJSON」。
- **严格基准门**（方案 A）：`datumGate(wkt)`——定义带 towgs84（含 WGS84 零参数）→ 放行；基准与 WGS84 等价（wgs84 / CGCS2000，差 <1 米）→ 放行并记录「基准 CGCS2000≈WGS84」；北京54、西安80等无参数老基准 → 拒绝，文案含「缺少基准改正参数（towgs84），严格模式不做近似变换…请转换为标准 EPSG 坐标系」。
- **变换泛化**：`transformViaDefinitions(collection, fromDef, toDef)` 任意可解析定义（EPSG 注册名 / WKT / proj 串）间变换；解析结果缓存。planCrsExecution 改收 `CrsLayerInput[]`（身份 + WKT），计划含 `targetDefinition` 与 `datumNotes`；4326/3857 保持注册定义快速路径。跨坐标系运算：输入对齐（align-input）→ 工作坐标系 4326（to-working）→ 结果回投目标（from-working），变换步骤全部记入 OperationRecord 的 crs 事实。
- **aeqd 米制缓冲**：meters/kilometers/miles/feet 在图层外接框中心的 aeqd 里按地面真米缓冲（伪度平面方案，见探测结论 7），圆形近似 32→64 边形（steps 8→16）；degrees 单位保持字面度数缓冲。OperationRecord 的 crs 事实新增 `bufferProjection: "aeqd"` 与 `datumNotes`。
- **导出补 crs**：LayerStore.exportTo 与 `GET /api/map/layers/:id/geojson` 在图层为标准 EPSG 时写 `crs: {type:"name", properties:{name:"EPSG:nnnn"}}`；未声明/无效不写。导出文件重新导入身份不丢。
