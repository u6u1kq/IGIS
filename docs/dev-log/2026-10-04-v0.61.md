# 2026-10-04 V0.61 总设置、图层顺序与报告钩子

在 V0.6 上追加。没有 git 提交。地图画布、空间分析表单字段、单层样式、GeoJSON 导出、RAG 检索、`var/spatial-audit` 和对话账本都保留。对话账本仍然只存角色、文本和时间，不存坐标。没有安装 pptxgenjs，没有写真实 PPT，也没有加预览库。新界面不解析 shp、gdb，新路径不调用 GDAL。没有比例尺或坐标系界面，没有 Electron、Tauri 或 GPL 依赖。

## 全局设置

- 模块名：`apps/desktop/ui`，`apps/cli/src/desktop-api.ts`，`packages/llm-dispatch/src/session-config.ts`。
- 变更内容：页右上角齿轮重新打开「全局设置」。里面是 API Base、密码框形式的 API Key、默认模型 DeepSeek-V4.1-Flash 与 local-mock。它和对话栏里的模型按钮弹窗读写同一份 `POST /api/llm/config`。模型按钮弹窗仍在，高级设置默认折叠。布局区有对话/地图宽度滑块、字号滑块，以及「空间分析面板自动展开」。滑块直接改 `--chat-flex`、`--map-flex` 和 `--ui-font-size`。保存默认只进 desktop-api 进程内存。「保存配置到后端」默认不勾选，勾选后才写 `config/llm.local.json`。页面不回显完整密钥。
- 接口契约变更：`GET/POST /api/llm/config` 增加 `chatRatio`、`fontSize`、`analysisAutoExpand`。未带这些字段的模型弹窗确认仍沿用上一份布局。DeepSeek 预设地址改为 `https://api.deepseek.com/v1`。
- 密钥：默认只在进程内存。未勾选时不写磁盘，并会去掉已有的 `config/llm.local.json`，这样重启后改回环境变量。响应只有掩码或「是否已配置」，没有 `apiKey` 字段。错误文字会先去掉密钥和 Bearer 片段。

## 测试连接提示

- 模块名：`apps/desktop/ui/app.js` 的状态文案。`POST /api/llm/test` 仍用原来的 `fetch`，没有重写 HTTP 客户端。
- 变更内容：上游状态码在界面上分开显示。400 是「请求格式错误！检查API Base URL是否以 /v1结尾」。401 是「API-Key无效，请核对密钥」。402 是「账号余额不足，需要充值」。429 是「请求频率超限，请稍后重试」。其他状态码显示原始数字。提示文字不包含密钥。

## 图层列表

- 模块名：`apps/desktop/ui` 的图层列表。样式编辑仍是原来的名称、透明度、填充色、轮廓色、轮廓宽度。
- 变更内容：列表行可以拖动，松手后用 MapLibre `moveLayer` 调整叠放顺序。右键菜单可以隐藏或删除。显示勾选和删除按钮仍保留。删除仍走原来的 `POST /api/map/layer/delete`。

## GIS项目报告-导出PPT

- 模块名：`apps/desktop/ui` 侧栏，`apps/cli/src/desktop-api.ts`。
- 变更内容：侧栏按钮和对话框标题都是「GIS项目报告-导出PPT」，不是「AI工具包」。主区域仍是地图加对话。表单有空间审计素材、知识库素材两个复选框，单独的模型下拉（DeepSeek-V4.1-Flash、local-mock），以及这一次任务自己的 API Base 和 API Key。下载 PPT 与网页内预览是单选，只随请求提交，不下载文件，也不渲染幻灯片。按钮「运行生成报告」提交后，后端返回模拟成功。
- 接口契约变更：新增 `POST /api/report/ppt`。标准输出只记路由、模型、两个素材开关、输出方式、API Base、是否带密钥和 `simulated: true`。不记密钥本身。

## 明确没改的部分

- 空间分析表单仍是缓冲、相交、裁剪、空间查询、统计，以及距离、单位、查询种类、属性筛选、数值字段、写入知识库和 GeoJSON 导出。执行和导出的业务代码没有重写。面板外面包了一层 `details`，只为总设置里的自动展开开关服务。
- `var/spatial-audit` 的记录格式和存储逻辑没有改。
- 对话账本 `var/desktop/messages.json` 仍只有角色、文本和时间。
- 没有调用 GDAL，也没有读取 shp 或 gdb。没有比例尺或坐标系控件。
