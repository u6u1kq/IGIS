## 三、授权契约落地（B1/B2/15）

- **ApprovalToken**（`packages/ai-boundary/src/capability-manifest.ts`）：tokenId/issuedFor/issuedBy/issuedAt/expiresAt/consumedAt 字段一次到位；`issueApprovalToken` + `consumeApprovalToken`（一次性、过期拒绝、issuedFor 绑定防跨操作复用）+ `issueAndConsumeApproval`（确认动作的统一消费入口）。V0.86 为内存同步消费；部署/MCP 接入时补持久化零返工。授权来源枚举 `ApprovalIssuer` 含 `mcp-client`，**AI 永远不在其中**。
- **B1 确认门**：`desktop-api.ts` chat 入口 `confirm: confirming`（仅当 pendingPlan.requiresConfirm 时生效）；`pending-plan.ts` 新起草/补齐槽位的路径不接受 confirm 授权（`finishComplete(..., false)`），合法确认只走 requiresConfirm 分支。
- **B2 授权字段剥离**：注册表 `map.delete/clearAll/dropDatabase` 删除 `confirm` 参数；`parsePendingPlan` 恢复计划时剥离 `AUTHORIZATION_FORBIDDEN_INTENT_FIELDS`（confirm/userConfirmed/approval/approved/token）。**行为变化**：模型/计划再带 `confirm:true` 在参数边界即被拒（"未知参数"），比确认门更早更硬；v079b/workflow-env-check 的对应断言按新契约更新（不变式不变：未授权删除不发生）。
- **approvalState 入记录**：OperationRecord 增量字段 `approvalState`（required/confirmed/confirmedBy/tokenId/consumedAt），executeGisOperation 默认写 `{required:false, confirmed:false}`；破坏性操作的记录带已消费 token 痕迹；授权状态不进模型可见面（allowlist 无此键）。

## 四、翻译层闭环（B3）与出站审计（B4）

- `loop.ts` 工具结果交模型前过 `releaseToModel`（gateway manifest 权限 + 脏载荷二次校验），越界降级为 boundary-rejected。
- `allowlist.ts` `numbers` 键只放行**扁平**数字数组，递归坐标结构一律剥掉。
- `llm-dispatch/http.ts` 出站审计 `var/llm-requests` 增加总量上限 `AUDIT_TOTAL_CAP`（50MB）按时间序淘汰（`evictAuditOverBudget`），保留 200 份计数上限不变。

## 五、留痕契约补全（17 个非空间状态变更入口）

`OperationKind` 扩到十族（+load/delete/rename/export/import，与 `AUDIT_REQUIRED_OPERATIONS` 对齐）；记录 schema 增量 `action`/`inputResources`/`outputResources`（旧记录读回兼容，不伪造字段）；新增 `recordNonSpatialOperation` 统一写入 var/operations。

入口接线（成功与失败都留痕）：

- 适配器：map.delete / map.clearAll / map.dropDatabase（带 approvalState）；map.load / io.read / map.exportGeoJson 的写入分支同样就位（注：这三者对模型/MCP 侧本就不是可见能力，模型侧在 rejectModelToolCall 处即被拦，可达的 load/export 留痕入口是桌面接口）
- map-http：/api/map/load、/api/map/rename、/api/map/layer/delete（local-ui 授权）、/api/map/export
- desktop-api：/api/import、/api/import/upload、/api/rag/clear（drop-database 授权）、/api/rag/delete、/api/documents/delete
- gdl-http：/api/gdl/load（run-gdl，脚本内空间步骤各有自己的记录）、/api/gdl/export

workflow-env 的统计表补零值键适配（工作流仍只统计五空间操作）。
