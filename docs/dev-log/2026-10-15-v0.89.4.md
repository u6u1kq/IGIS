# V0.89.4 预览字段、坐标系原文与侧栏

## 已完成

- 资源预览增加字段名。仍不放坐标、WKT、几何或属性值，也不把这些加进模型载荷。
- 局部平面坐标系不能缓冲时，工具结果和聊天回复使用坐标系策略里的原句，错误码是 `crs-refused`。说明文字里的「面积/长度」不再被当成路径，因此不会改写成 `LOCAL_DATA_ACCESS_ERROR`。盘符、路径斜杠、`..` 和裸文件名的判断不变。同一工具、同一错误码连续两次仍会停止。
- 聊天这一轮带上当前对话的图层范围。范围内解析图层名；范围为空时不把整个图层库交出去。没有对话范围的入口仍查整个图层库。没有另写一套解析器。
- 资源树从地图下方的滚动区移到地图旁边，和对话列一样是独立侧栏，自己滚动。标题、新建、图层、文件、预览、显隐、样式、顺序和按选中图层导出都还在。没有恢复空间分析表单。

- 不重试 micromamba 对 python 3.11.11、gdal 3.9.2、numpy 2.1.3 的求解，也不把 osgeo 写成可用。
