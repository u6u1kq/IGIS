# V0.89.8

两个图层的坐标系都是未声明时，`distance`、`nearest`、`distance-matrix`、`nearest-exact` 在原坐标上计算。结果写明单位是坐标单位，不是米。一边有坐标系、一边没有，这四项仍拒绝。缓冲在未声明坐标系上仍拒绝。

`map.vertices` 使用已安装的 `@turf/explode`，把面或线的每个节点写成点图层。属性从原要素复制。环上重复的闭合点各保留一点。

`/api/environment` 的 `summary` 只列出未通过项，句子里写缺什么、怎么处理。开发启动不把仓库里缺少的 `node_modules/tsx/package.json` 当成故障。目录包在 `IGIS_REQUIRE_LOCAL_RUNTIME=1` 时，缺 tsx、地图库或 `gdal.wasm` 会写出对应文件。缺 Python/osgeo 的句子写明只影响重投影。页面用这份 `summary`，不再把没有 `message` 的结果写成「请求失败」。

切换对话时，地图挂载 `GET /api/workspace/layers` 返回的该对话图层编号。浏览器里只保留中心、缩放和叠放顺序。切走不删除另一个对话的文件和图层。

属性连接仍无开源函数可接，记在 `docs/TOOL-GAPS.md`，本版没有实现。

`link.exe` 位于 Visual Studio 2022 Build Tools。`tauri-cli` 2.12.3 已安装。`apps/desktop/src-tauri` 编出 `target/release/igis.exe`。窗口地址是 `http://127.0.0.1:39221`。`start-igis.cmd` 先等本机接口，再打开这个窗口。`dist/igis-win` 的启动脚本仍打开系统浏览器，没有带上这个可执行文件。
