      空间操作审计

      选择模型

      local-mock 在本机模拟，不使用地址和密钥。其他预设只填入名称和地址，都可以改。自定义时自己填写模型名、API Base URL 和 API Key。

      默认不写入磁盘。不勾选时密钥只留在服务进程内存，页面刷新后输入框为空，进程重启后改用环境变量。勾选后写入 config/llm.local.json。用户配置优先于环境变量。页面不会回显完整密钥。

      导入 GIS 文件

      从电脑选择数据

      可以一次选择多个图层和各自的配套文件。Shapefile 请把同名的 .shp、.shx、.dbf 一起选入。GeoTIFF（.tif、.tiff）走地图加载：平面图画出文件范围，栅格编号留给三维和后续工具。缺少配套时按图层说明，齐全的面图层会合成一个面图层。坐标系文件 .prj 建议一并上传，没有写明的坐标系不会猜测。单次最多 1 GB。

      全局设置

      界面语言

      只切换界面文字。已经保存的对话内容保持原样。

      界面主题

      立即切换；偏好保存在本机浏览器。

      模型

      与对话栏里的模型窗口共用同一份配置。模型名、接口地址和密钥都可以改。用户配置优先于环境变量。页面不会回显完整密钥。

      界面布局

      默认关闭。打开后，助手回复显示本地解析轨迹。本地运算的耗时始终显示。

      记忆

      只保存你明确要求记住的偏好和事实。不能含密钥。会写入本机 var/memory，并在系统提示里作为偏好附上。偏好不决定这一轮要做什么，也不指定用哪一层。

      MCP 客户端

      可选。填写外部 MCP 进程的命令和参数，对话时会尝试把它的工具接到现有调度器。网页应用不依赖 Cursor。不要在命令里写密钥。
