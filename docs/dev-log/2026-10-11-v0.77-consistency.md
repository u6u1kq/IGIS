# 2026-10-11 V0.77 GIS 一致性收口（补记）

本文为 2026-10-11 补记。V0.77 的实际开发早于本日志，内容依据当时的 TASK 文档与当前代码核对。

V0.77 只做四件事：CRS 正确性、缓存正确性、查询语义、图层生命周期。不做 reprojection、统一执行器、完整 OperationRecord。

## 模块名

`packages/spatial-ops/src/service.ts`，`result-cache.ts`，`text.ts`，`ops.ts`，`normalize.ts`；`packages/surtgis/src/core/layer-store.ts`。

## 变更内容

- **CRS**：空间运算只接受显式 EPSG:4326。未声明、已知但不是 4326、两个 CRS 不一致都拒绝。GeoJSON 没有 CRS 时落为「未声明」，不再自动标成 4326。没有 reprojection，没有改 Turf。
- **缓存**：键含运算、输入图层 id、每层当前 CRS 标签、距离、单位、输出名、查询种类、属性筛选和几何内容哈希。删层时按结果层和输入层双向失效；重命名只改缓存文件里的名称元数据，不重算几何；回退后 stale 缓存不能复活已删图层（命中必须图层仍在目录里）。缓存写失败时撤下刚建的结果图层，清理也失败时两个失败都写进错误文案。
- **查询**：`null == null` 为 true，`!=` 取反；类型不同的 `=` 为 false；字符串保持字符串（`"10.0"` 不会变成 10）；大小比较只在双方都是数字时进行。空间谓词与属性筛选同时给出时两者都必须满足。自相交要素由 `readyForTurf` 在算子前过滤，源图层不动。
- **图层生命周期**：删除源图层时派生几何保留，只摘除指向已删路径的 source 引用；绝不删除源数据文件；导出永不覆盖已有文件。
