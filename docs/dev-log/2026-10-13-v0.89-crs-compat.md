# 2026-10-13 V0.89 坐标系兼容、聊天交互与能力补全

## 主题

- 聊天交互（G1）：翻阅不打扰、"回到最新"按钮、发送后默认跟随模型输出、对话标签显示当前模型名。
- 坐标系兼容（G2）：局部/工程坐标系身份扩展（无 EPSG 的 WKT 不再判无效）、平面度量与平面构造放行、平面坐标示意显示、DBF 字段编码修复。
- 能力补全（G3）：split 三件（点分割线/多部件拆分/线分割面）、空间聚合、距离矩阵、精确最近距离、GDL QUERY/STATS/MEASURE 三语句、字段分级保守默认。

## 发现

- 教材实验数据普遍是投影坐标 + WKT 无 AUTHORITY（局部平面几 km、UTM 数十万、全国百万级），旧判定一律收成"无效身份"，导致空间分析全被 CRS 门拦住、地图把米当经纬度画不出。
- 对话每次重绘都把选中轮 scrollIntoView，选中轮在顶部时视口被拉回顶端，翻阅历史被打断。
- DBF 字段名经 GDAL-WASM 按 UTF-8 解码，GBK 编码的中文字段名成乱码。
- 模型侧可见面没有字段名单，无法按字段发起分组统计/重分类。

## 修复

- CRS 身份（`packages/surtgis/src/core/crs-identity.ts`）：新增 `planar` 身份（已声明投影/局部平面，WKT 无 EPSG 代码），同一段定义文本才视为同一平面坐标系；`identifyCrs` 对 WKT 先取 AUTHORITY，取不到才收平面身份。
- CRS 策略（`packages/spatial-ops/src/crs-policy.ts`）：`PLANAR_OK_OPERATIONS` 放行平面构造（voronoi/凸包/MBR/质心/分幅/几何转换/分割/空间聚合/精确最近）与平面度量（面积/长度/距离/距离矩阵/最近距离）；缓冲、叠加、融合、简化、重投影仍要标准 EPSG。平面度量要求 WKT 可证明长度单位（`planarUnitToMeter`），证明不了只禁度量、不禁构造。
- 平面度量（`packages/spatial-ops/src/ops.ts`）：面积（鞋带公式）、长度、距离按坐标平面欧氏几何计算，乘单位系数得米；球面公式保留给 EPSG 路径。
- 平面渲染（`apps/desktop/ui/app.js`）：非经纬度坐标按 1 单位 ≈ 1/111320 度线性映射示意显示（仅显示用，图层库数据不变），提示"局部平面坐标按示意比例显示，位置非真实地理位置"。
- DBF 编码（`packages/gdal-wasm-adapter/src/runtime.ts`）：字段名/属性值按 C 字符串原始字节解码——先严格 UTF-8，再 GBK，最后 Latin-1，不依赖 GDAL 编码探测。
- 聊天交互（`apps/desktop/ui/app.js`、`index.html`、`app.css`、`i18n.js`）：滚动跟随状态（贴底才跟随）、"回到最新"悬浮按钮、发送消息即恢复跟随、重绘保持阅读位置、对话标签显示当前模型名（`modelLabel()`），引用文本改从 `dataset.turnText` 取原文。
- 能力补全：`map.splitLine`（点分割线）、`map.explode`（多部件拆分）、`map.splitPolygon`（线分割面，交点节点化 + polygonize）、`map.spatialAggregate`（点入面计数 `_count`/`_sum`/`_mean` + 摘要）、`map.distanceMatrix`（逐对距离统计，规模上限默认 10000）、`map.nearestExact`（双向顶点采样，优于单代表点）。全部走契约登记 → 执行边界 → OperationRecord。
- GDL（`packages/gdl/`）：新增 `QUERY 图层 WITH 筛选 AS 结果`、`STATS 图层 ON 字段`、`MEASURE AREA|LENGTH 图层 / MEASURE DISTANCE 甲 TO 乙`；宿主转 query/stats/area/length/distance，摘要只出数字。
- 字段分级（`packages/ai-boundary/src/levels.ts`、`packages/ai-translation/src/allowlist.ts`）：字段名单可见（`fieldnames` 入投影白名单），敏感字段名黑名单过滤（姓名/证件/电话/住址/邮箱/收入/密码等 + 英文同义），属性值仍只出聚合、单字段名命中黑名单不放行。通用词（name/名称/id）不进黑名单。

## 行为变化说明

- 原判"无效身份"的 WKT（无 EPSG）现为"局部平面"：平面构造与平面度量放行，缓冲/叠加/融合/简化/重投影仍拒绝，拒绝文案列明可用操作。
- 模型可见面新增字段名单（过滤敏感字段名）。属性值可见性不变。
- `GEOGCS["WGS 84"]` 类证明不了 EPSG 的 WKT 从"无效"改为"局部平面"；真正无法解析的文本仍为"无效"。
