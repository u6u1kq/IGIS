# 工具缺口

这里只记录还没有实现的工具。依赖里已经有、并且已经接到产品上的函数，不记在这里。

窄字段计算、字段等值内连接、栅格整型、NoData、邻域平滑，以及 `invdist` / `nearest` / `linear` 点插值和留出误差，已经是本机工具。克里金、汇水、剖面和填挖方见 `docs/dev-log/2026-10-17-v0.93.2.md`。

## 任意字段脚本

按任意脚本或 SQL 给要素写属性。

`map.calculateField` 只做加减乘除、比较和 `if`。不执行脚本或 SQL。

状态：未实现。

## 地层体里的断层

按断层面错开地层。

`map.geologyModel` 只用界面点和产状建连续地层，不接收断层数据。

状态：未实现。

## 降雨滑坡的径流汇流和非饱和入渗

坡面上产生的径流流到下坡像元再入渗，以及按土水特征曲线算非饱和带。

`map.rainfallLandslide` 每个像元单独入渗，不做汇流，只用饱和模型。

状态：未实现。

## 有空值或超长时段的坡面径流

带空值像元的高程栅格，以及降雨或模拟超过 24 小时的情景。

`map.rainfallRunoff` 遇到空值就拒绝，时长上限 24 小时，网格超过 4096 格时变粗。

状态：未实现。
