# V0.89.2 至 V0.89.6

各版细节仍以对应 dev-log 为准。这里只列相对 V0.89.1 之后、已经进当前代码的行为。

## V0.89.2

桌面接入本地 Python GDAL 进程桥，设置可关闭。重投影在缺少源 CRS 时拒绝，并固定传统 GIS 轴序。旧图层的 `invalid` / `wkt-no-epsg` 按已存 WKT 重识别为平面身份。上传文件进入当前对话目录；删对话时清理对应文件和未被引用的图层。地图接受文件拖放。同一工具、同一参数、同一失败重复两次后停止。新指令前自动保存检查点，可回退后续轮次并把原指令放回输入框。当时环境没有 `osgeo`，真实重投影链未跑通。

## V0.89.3

解释器可在下一次请求更换：面板路径写入 `var/gdal/interpreter.json`，留空走托管环境并压过 `IGIS_PYTHON`。桌面和 MCP 共用。锁文件为 `config/gdal-python.lock.json`。资源树放在地图旁。失败停止改为规范工具名加错误码。裸栅格名在当前对话工作区解析。当时 conda-forge 解不出 python 3.11.11、gdal 3.9.2、numpy 2.1.3。

## V0.89.4

预览显示字段名，不含坐标和属性值。平面坐标系拒绝缓冲时保留原文和 `crs-refused`，不再改写成文件访问失败。有对话范围时，图层名只在该范围内解析。资源树在地图旁边的侧栏里自行滚动。

## V0.89.5

已声明投影且单位为米时，缓冲和裁剪在该平面计算。没有投影或证明不了单位的局部坐标仍然拒绝。用户文本里有 `EPSG:` 时，先重投影再对新图层做原来的运算；没有代码则问一次。托管环境改为 python 3.11.17、gdal 3.13.3、numpy 2.4.6，本机 `from osgeo import gdal` 已通过。普通几何和坐标仅在设置中声明后进入模型。启动检查 Node、tsx、地图库、wasm 和 osgeo。目录包脚本输出 `dist/igis-win`，启动后打开的是系统浏览器。

## V0.89.6

移出未接入启动链且没有运行函数体的包和演示入口。矢量内核与具名工具保留。说明见 `2026-10-15-v0.89.6.md`。
