# 2026-10-05 V0.71 自由选模型、报告页签与预制数据库

在 V0.7 上追加。没有 git 提交，没有改 git 配置。对话、地图、图层库、GDL、空间运算、RAG、来源账本、空间审计和 PPT 生成都还在。账本形状没有改，也不会开始记坐标。密钥不进账本、空间审计、控制台或错误文字。没有 GPL/LGPL/AGPL 新包，没有 qgis-wasm，没有 LoRA，也没有把坐标写成训练样本。没有做 shp/gdb 解析。

## 模型选择

- 模块名：`packages/llm-dispatch/src/session-config.ts`，`packages/llm-dispatch/src/index.ts`，`apps/cli/src/desktop-api.ts`，`apps/cli/src/report-ppt.ts`，`apps/desktop/ui`。
- 变更内容：
  - 模型对话框和齿轮里的模型区不再写“请用 DeepSeek”、地址必须是 `api.deepseek.com`，或 `/v1` 是 DeepSeek 的要求。
  - 预设是：local-mock、DeepSeek-V4.1-Flash、千问、Grok、自定义。千问和 Grok 的地址来自原来的 `getLlmProviderProfile`，请求仍走现有的 OpenAI 兼容 chat/completions，没有新的厂商 HTTP 客户端。
  - 预设只填入模型名和 API Base URL，用户可以改。自定义一行由用户自己填模型名、地址和密钥。
  - local-mock 仍是本机模拟，不使用地址和密钥。只有模型名正好是 `local-mock` 才走模拟；提供方 `local` 加上别的模型名时，按用户填写的地址调用。
  - 用户已确认的配置优先于环境变量。密钥为空时才回落到该提供方的环境变量。未勾选「保存配置到后端」时密钥只留在进程内存。
  - 测试连接仍在。HTTP 400 的中文提示改为：请求格式被拒绝，请检查 API Base URL 和模型名。401、402、429 的提示没改。
  - 报告页里的模型也是同一套预设加可编辑的模型名，不再是只有 DeepSeek 的下拉框。
- 接口契约变更：
  - `POST /api/llm/config` 增加 `choice`（`local-mock`、`deepseek`、`qwen`、`grok`、`custom`）、`providerId`，`model` 改为实际模型名。仍接受旧的 `model: "local-mock"` 和 `model: "DeepSeek-V4.1-Flash"`。
  - `GET /api/llm/config` 增加 `choice`、`label`、`presets`。`model` / `modelId` 是实际模型名，响应里仍没有完整密钥。
  - `POST /api/llm/test` 使用提交的模型名、`providerId` 和地址，不再固定发给 `deepseek-v4.1-flash`。
  - `POST /api/report/ppt` 的 `model` 改为任意模型名，增加可选 `providerId`。`local-mock` 和旧的 `DeepSeek-V4.1-Flash` 仍可用。路由没有换。
- 未解决问题：
  - 千问、Grok 的默认模型名是 `qwen-plus`、`grok-3`，只是可改的默认值，没有用真实密钥打通过。
  - 自定义模型在密钥为空时回落的是 `LOCAL_LLM_API_KEY`，不是某一个云厂商的密钥。

## 预制数据库

- 模块名：`packages/finetune/src/foundation-db.ts`，`packages/finetune/src/index.ts`，`apps/cli/src/desktop-api.ts`，齿轮里的「预制数据库」。
- 变更内容：
  - 这是给 v1.x 微调做的底座，不是训练。没有跑 LoRA，也没有把坐标导出成样本。
  - 使用已有的 sqlite-wasm-vec，库文件和 RAG 的 `var/rag` 分开，在 `var/foundation/tool-traces.sqlite`。`var/` 本来就被 gitignore，数据库文件没有进版本库。
  - 表只有指令文字、函数调用 JSON（工具名和非坐标参数）、来源 `synthetic`、许可证标记、创建时间。没有几何列。
  - 第一次使用时在进程里生成 8 条合成记录，并写 `var/foundation/manifest.json`（条数、schemaVersion、sha256、createdAt）。没有假装去下载一个不存在的地址。样本里没有真实地理。
  - 含坐标、WKT、WKB 或 GeoJSON 几何的插入会被拒绝，错误文字不回显原文。
  - 齿轮里有「下载预制数据库」，不是新页面。
- 接口契约变更：
  - `POST /api/foundation/prepare` 返回清单。
  - `GET /api/foundation/file` 下载 sqlite。
  - `POST /api/foundation/sample` 追加一条合成样本；坐标或几何返回 400。
- 未解决问题：预制库不会自动跟对话工具轨迹同步，只在显式准备或下载时生成。以后的微调还没做。
