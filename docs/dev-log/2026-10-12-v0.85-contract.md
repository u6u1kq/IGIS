## 任务 1：法律规范禁止清单（结论）

- **依赖许可实测**：7 个直接依赖全部宽松许可（MIT×4：MCP SDK/Turf/proj4/zod、BSD-3：maplibre-gl、Apache-2.0：sqlite-wasm-vec、gdal-js 内含 GDAL MIT/X11），无 copyleft，商业化无障碍；`config/licenses.lock.json` 已有审查记录；license-check 拒绝 GPL/LGPL/AGPL 直接链接。
- **测绘数据保密**：坐标/几何进 AI 通道是硬性禁止（L1）——L2 语义投影 + 出站审计已实现，契约定为不可协商。
- **AI 行为禁止**（L2）：不伪造授权/不自认破坏性操作/不绕过审计——门控已有，ApprovalToken 待 V0.86。
- **数据产权**（L4/L5）：用户数据本地存储；教材数据仅测试不得商用。
- **结果责任**（L6）：AI 结果附"仅供参考"告知，文案待 V0.86 补。

## 任务 2：接口与框架审查（结论）

**接口清单**（三类，2026-10-12 实测）：
- HTTP 端点约 40 个：desktop-api（health/llm-config×2/llm-test/foundation×3/settings×2/messages/conversations×5/memory×3/documents×3/rag×4/import×2/chat）+ map-http（layers/geojson/load/rename/layer-delete/layer-style/layer-order/export/spatial-run/audit + vendor 静态）+ gdl-http（parse/load/export）
- AI 工具注册表 22 项：数据查看 6（list-layers/get-layer-metadata/get-sample-feature/io.read/io.listLayers/map.list）、空间分析 5（buffer/intersect/clip/query/stats）、图层管理 9（load/style/setVisibility/setOrder/zoomToLayer/exportGeoJson/delete/clearAll/dropDatabase）、工作流 2（gdl.run/gdl.describe）
- 包公开 API：spatial-ops（SpatialService/openSpatialStack/executeGisOperation/rollbackOperation）、surtgis（LayerStore/overlay/crs）、ai-translation、ai-boundary、workflow-env

**串联断点**（入口×环节，违反"入口→Translation→Request→executeGisOperation→Runtime→记录"链）：
1. loop.ts:462 用 `projectForModel` 不经 gateway manifest 二次校验（应 releaseToModel）
2. allowlist 的 `numbers` 键放行坐标递归嵌套
3. `map.delete` 注册表 schema 含 `confirm` 参数（AI 可带授权字段进意图）
4. parsePendingPlan 恢复时接受任意标量含 confirm/userConfirmed（对话文件可自带授权）
5. desktop-api chat 入口 body.confirm 直接下传为授权（一步绕过两步确认）
6. GDL 的 findByName（同名取最上层）vs Chat/MCP 的 ambiguous 拒绝（解析语义双轨）
7. stats/属性查询过 rejectCallerOverride（与"非空间运算不要求 CRS"矛盾）

**内部目标统一性**：GdlHost 缺 query/stats（工作流能力不完整）；GDL `CRS 4326` 判 invalid（parser 假设过时）；load/delete/rename/export/import 无 OperationRecord（留痕契约未覆盖）。
