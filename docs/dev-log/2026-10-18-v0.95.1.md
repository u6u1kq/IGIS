# 2026-10-18 V0.95.1

专业权重不再只有一份。安装写入 `var/models/igis-pro/slots/`，并把这一份设为当前的 `model.json`。设置里可以改用库里的另一份。克里金和汇水仍只读 `model.json`。同名文件再次安装会替换同名的那一份。

导入对话框可以一次选择多个图层主文件和配套文件。缺 `.shx`、`.dbf` 或 `.mid` 的图层在结果里单独列出，其他齐全的图层继续载入。齐全的面图层交给已有的 `SpatialService.merge`，合成一个面图层。坐标系没有写在文件里时不猜测 EPSG；合并被坐标系拒绝时，这些面仍然分开载入。单次上传仍是 128 MB。

用户说「打包训练数据」时，本机先扫描用户给出的目录，只把索引交给模型：种类、相对名称、文件自己写明的 EPSG 和是否米制、要素数量、数值字段名、outlet 是否从 1 连续。索引里没有坐标、范围、高程和绝对路径。模型按 `field`、`streams` 整理 `training.json`，不运行训练程序。贴来的训练报错会先去掉路径，再只解释程序自己的退出说明。实验权重不能说成可以放进公开安装包。

未改 `package.json` 与窗口模块的 `0.3.0`。
