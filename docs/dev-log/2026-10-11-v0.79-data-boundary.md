# 2026-10-11 V0.79 数据边界（补记）

本文为 2026-10-11 补记。V0.79 的实际开发早于本日志，内容依据当时的 TASK 文档与当前代码核对。

在 V0.78 的 ai-boundary/ai-translation 基础上，把模型可见面收成白名单投影。

## 模块名

`packages/ai-translation/src/allowlist.ts`，`gateway.ts`，`ai-to-local.ts`，`local-to-ai.ts`；`packages/llm-dispatch/src/loop.ts`；`packages/spatial-ops/src/adapter.ts`。

## 变更内容

- 模型可见的观察只保留白名单键（ok/code/message/operationType/图层标识与名称/参数摘要/统计值/operationId/cached/durationMs 等）；几何、坐标、路径、脚本、确认字段一律不出模型。
- Chat 工具循环给计划调用挂 `CLOUD_PROVENANCE`（source、aiOrigin、translationUsed），本地结果与模型回包都经 `projectForModel` 投影。
- `map.list` 返回 L2 图层视图与 `availableOperations`（AI_SPATIAL_OPERATIONS），模型据此选择操作。
- AI 意图翻译 `translateAiIntent` 把模型意图收成本地操作请求，文件系统/GDAL 直调/原始几何类意图直接拒绝（filesystem-rejected/gdal-rejected/geometry-rejected）。

## 验证

`v079-boundary-check` 与 `v079b-boundary-check` 通过：白名单投影、拒绝码、模型可见面不含坐标。

## 未解决问题
