# 2026-10-13 V0.89.1 审查修复

产品版本 V0.89.1。上一提交 `6456a3a` 是 V0.89。

## 主题

审查后的对话范围、回合归属、失败回复、地图读数和模型上下文修正。没有新的空间能力。

## 修复

- 对话范围（`packages/llm-dispatch/src/layer-context.ts`、`apps/cli/src/desktop-api.ts`、`apps/desktop/ui/app.js`）：`layersForConversationScope` 只保留请求里 `scopeLayerIds` 命中的图层。范围为空、或范围里没有该图层时，不把图层库全集交给模型。发送时记下当时的 `scopeLayerIds`，确认重发沿用同一份。
- 回合绑定（`apps/cli/src/conversations.ts`、`desktop-api.ts`、`app.js`）：`record` / `appendTo` / `setPendingPlanFor` 按发起时的 `conversationId` 读写，用户消息、助手回复和 Pending Plan 不写到后来切到的活动对话。流式事件和结果只在仍停在该对话时渲染。删除对话时丢掉该对话的地图范围。
- 失败回复（`desktop-api.ts`）：用户消息已经写入后，这一轮抛错会再写入一条助手回复（`turnStatus: "failed"`，正文是抹掉密钥后的错误），事件流以 `done` 结束。错误回复写不进去时，仍按原来的失败响应告诉当前连接。
- 用户前缀（`desktop-api.ts`、`app.js`）：气泡上的「我：」/「Me:」只用于显示（`role.user`）。发送和入库前用 `stripDisplayedRolePrefix` 去掉这一层前缀。
- 地图光标（`index.html`、`app.js`、`app.css`、`i18n.js`）：鼠标在地图上移动时，`#map-cursor` 显示经纬度到小数点后五位；当前有示意显示的可见图层时，文案标明这是屏幕上的经纬度窗口，不是图层原生坐标系。鼠标离开后清空。
- 图层列表里的 crsLabel（`app.js`）：图层列表和样式行显示 `crsLabel`。示意显示的图层在标签后加上「示意显示，不是该图层坐标系坐标」；没有标签时示意图层写「未声明」。
- 图层详情（`index.html`、`app.js`）：`#layer-detail` 在选中图层时写出名称、几何类型、要素数、字段名和坐标系标签。
- 白名单 crsLabel（`packages/ai-translation/src/allowlist.ts`、`v079b-boundary-check.ts`、`gis-prompt.ts`）：允许名单增加 `crslabel`。`crs`、`bbox`、`extent` 以及坐标、WKT、路径仍拒绝。系统提示改为：当前对话范围内的摘要含字段名和 crsLabel，crsLabel 只是标签，不是坐标，也不能当成投影坐标。
- 可续计划 / priorInstruction（`pending-plan.ts`、`dispatch-policy.ts`、`desktop-api.ts`）：执行决议带上 `sourcePlan`。本地执行因缺图层或缺参数失败（`stopReason === "step-failed"`，且不是坐标系/EPSG/投影类拒绝）时，`continuablePlanAfterFailure` 把失败步的图层槽和距离槽重新标成缺失，计划里只有标量和原句。`priorInstructionAfterClarification` 在 V0.89 已存在；本版在上一轮助手只是澄清、且原文不像几何时，把那条用户指令作为 `priorInstruction` 交给调度。含几何文本的不传。
- running_tools 不入库（`desktop-api.ts`、`app.js`）：`persistedThought` 只保留模型推理正文。`running_tools`、`understanding`、`starting` 以及其它 status 不写入对话。界面上 `thought === "running_tools"` 不再显示成「正在调用工具」。
- 量词「两」（`local-intent.ts`）：「两个」「两边」一类后面跟着个/层/条/只/张/次/边/种/份/块/名/点/样的「两」「二」不是米。「两百」「两米」仍是距离。整句、过长碎片、以及夹着「两个」「一下」等虚词的碎片不再当成图层名；已经载入的图层名保持原样。
