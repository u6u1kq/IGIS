# V0.89.5

已声明投影且长度单位为米的平面坐标系，缓冲和裁剪在该平面上计算。没有投影或证明不了单位的局部坐标仍然拒绝。

坐标系拒绝且用户文本里有 `EPSG:` 代码时，先重投影到新图层，再对新图层做原来的运算。没有代码时问一次，不挑选目标。

托管 GDAL 环境锁为 python 3.11.17、gdal 3.13.3、numpy 2.4.6。本机 `from osgeo import gdal` 已通过。

普通工程数据的几何和坐标只在使用者勾选声明后进入模型。控制点、转换参数、军事禁区、重力点和大地控制这些图层名不附带几何。工具参数仍不接收模型写回的几何。

启动时检查 Node、目录内 tsx、地图库、gdal wasm，以及 osgeo。目录包设置 `IGIS_REQUIRE_LOCAL_RUNTIME=1` 时，前四项缺一则进程退出。osgeo 缺失只标明重投影不可用。

目录包脚本是 `apps/cli/src/package-win.ts`，输出 `dist/igis-win`。该目录的启动脚本打开系统浏览器，不是独立窗口。

浏览器界面未验证。
