# V0.89.3 解释器热切换、资源树与失败指纹

## 已完成

- 托管 GDAL Python 与自定义解释器两条路。锁文件 `config/gdal-python.lock.json` 固定 micromamba 2.0.5、python 3.11.11、gdal 3.9.2、numpy 2.1.3、频道 conda-forge。前缀 `var/gdal-python` 与 `var/micromamba` 已写入 `.gitignore`。没有改 `config/gdal.lock.json`（那份仍是 gdal-js）。
- 进程桥每次启动都重新读取命令。面板保存在 `var/gdal/interpreter.json`：空字符串是托管模式，并压过 `IGIS_PYTHON`；从未保存时 `IGIS_PYTHON` 仍是无界面回退。自定义路径只作为下一次进程的启动命令，不改用户自己的 Python。桌面和 MCP 读同一份文件。保存后下一次请求即换解释器，`GET /api/external/status` 会探测新命令。创建失败时状态附上 `var/gdal/bootstrap-error.txt`。
- 地图侧栏改为资源树：标题、新建、可折叠的图层与文件、预览（名称、类型、数量、CRS 标签）。图层仍保留显隐、样式和顺序。空间分析表单和「打开页面时显示空间分析」已去掉。导出使用资源树里选中的图层。`/api/spatial/run` 与聊天工具路径仍在。
- 失败停止键改为规范工具名加错误码。图层名、栅格名、输出名和参数别名不再把计数清零。不同工具不共用计数。`confirm-required` 不计入。第二次相同失败停止本轮并告知用户。
- 已有 DEM/栅格工具没有加新算法。裸文件名（无盘符、无斜杠、无 `..`）不再被当成路径。当前对话工作区内按文件名找栅格，不接受模型传入的路径；没有对话时仍用 `var/rasters`。坡度、坡向、山体阴影和栅格计算把产物登记为短名，供同一对话后续按短名找到，不上图。等高线仍加载矢量图层。
- 系统提示里的「A / B」会被整段当成路径而从模型请求里删掉。提示改为顿号，真实路径判断不变。
