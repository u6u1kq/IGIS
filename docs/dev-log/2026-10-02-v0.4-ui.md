# 2026-10-02 V0.4 试用界面

本轮只改浏览器里的试用页面。服务端路由、RAG、账本、GIS 读取和模型 HTTP 适配器没有改。地图画布和空间分析留到 V0.5。未创建 git 提交。

## 试用界面

- 模块名：`apps/desktop/ui`（`index.html`、`app.css`、`app.js`）。页面仍由 `apps/cli/src/desktop-api.ts` 从该目录原样读出，监听 `http://127.0.0.1:39221`。
- 变更内容：去掉页顶说明，对话区成为整页主表面。模型下拉移到输入框下方的横条工具栏，只有两个选项：`DeepSeek-V4.1-Flash` 与 `local-mock`（值使用 ASCII 连字符）。页右上角齿轮打开高级设置，里面是自定义 OpenAI 兼容接口和 API 密钥。选中 DeepSeek-V4.1-Flash 时，页面写入预设接口 `https://api.deepseek.com`、模型名 `deepseek-v4.1-flash`，提供方仍是现有的 `deepseek`。选中 `local-mock` 时，提供方为 `local`、模型名为 `local-mock`、接口留空，沿用原来的本机模拟，不发起云端调用。GIS 导入不再占左侧大卡片，改为工具栏上的「导入 GIS」按钮，对话框里保留绝对路径、写入本地知识库的复选框、预处理按钮和运行状态。设置仍通过原来的 `PUT /api/settings` 写到已被忽略的 `config/llm.local.json`。
- 接口契约变更：无。前端继续调用现有 `GET/PUT /api/settings`、`POST /api/import`、`GET /api/messages`、`POST /api/chat`。请求体字段名和含义没有改：`providerId`、`model`、`baseUrl`、`apiKey`、`ragTopK`、`ragEnabled`，以及导入的 `absolutePath`、`indexRag`，对话的 `text`、`ragEnabled`。
- 未解决问题：地图画布和空间分析留到 V0.5。下拉不再列出千问和 Grok；若本地配置里仍是这两种提供方，页面会提示重新选择，在用户选择或保存之前不改写该配置。已保存的 `deepseek` 若模型名不是 `deepseek-v4.1-flash` 或接口为空，打开页面时会按预设写回。已保存的 `local` 若还带着接口地址，打开页面时会改回本机模拟。自定义接口只在 DeepSeek-V4.1-Flash 下随保存写入；`local-mock` 始终把接口留空，以保证本机模拟。
