# V0.87 能力补全（2026-10-12）

依据：能力缺口清单中的高把握范围（不含重投影）。零安全层改动，四契约约束下扩能力。
新增 12 个 AI 能力（工具级），全部走「CAPABILITY_MANIFEST 登记 → executeGisOperation → OperationRecord → check」流程。

## 新能力（12）

| 工具 | 族 | 危险级 | 语义 |
|---|---|---|---|
| map.area | measure | read-only | 面积统计（平方米，球面精确），合计/最小/最大/平均 |
| map.length | measure | read-only | 线长统计 + 面周长单独统计（米） |
| map.distance | measure | read-only | 两图层最近距离统计（min/max/mean） |
| map.nearest | measure | derive | 逐要素标注到另一图层最近距离，输出图层带 `_dist`（米） |
| map.convert | geometry-convert | derive | 线→面（闭合环）/ 面→线 |
| map.dissolve | geometry-convert | derive | 面融合（可按字段分组，各组融为一面） |
| map.merge | geometry-convert | derive | 同类型图层合并（类型不同明确拒绝） |
| map.simplify | geometry-convert | derive | 几何简化（容差米，aeqd 伪度平面机制与米制缓冲同源） |
| map.groupStats | attribute | read-only | 按字段分组统计数值字段（count/sum/mean，≤50 组） |
| map.reclassify | attribute | derive | 字段值映射重分类（`1=耕地;2=林地`，固定映射表，不做公式引擎） |
| map.qualityCheck | attribute | read-only | 空值/空串/去重/值域 + 无效几何计数（只出标量） |
| map.splitByGrid | grid | derive | 格网分幅（列×行 1-6，逐幅裁剪，结果带 `_sheet`） |

## 语义约定（如实）

- **度量按坐标计算**：走与 derive 相同的 CRS 对齐管线（planCrsExecution + prepareOperands → 工作 CRS 4326），球面精确（turf area/length/distance）。
- **nearest 的距离语义**：点图层为精确值；线/面 A 侧按**要素代表点**（pointOnFeature）计算，工具描述与结果摘要均注明——不假装是精确边界距离。
- **重分类是固定映射表**，明确不做表达式引擎（避免注入面）；字段计算/条件赋值仍在缺口清单。
- **分幅输出单层 + `_sheet` 字段**（跨幅要素在多幅各留一份），不是多文件分幅。
- 未命中/退化几何（如 2 点线转面成退化环）跳过并计数，不静默产出坏几何。
