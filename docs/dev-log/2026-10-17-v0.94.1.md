# 2026-10-17 V0.94.1

地图栏可以在平面和三维之间切换。三维页占原来的地图栏，左侧对话还在。这一页只列出当前对话的图层标识和栅格句柄，不接收坐标。

`map.waterLevel` 用现有高程栅格计算水深：水面高程减地面高程，不大于 0 的像元记为 0。产物是水深栅格句柄，可以在平面图上接着用。没有流速，也没有时间。水位没写就追问。地理坐标拒绝。

`map.layerStack` 登记从下到上的图层顺序和层间竖向间距。少于两层时不写登记，也不出图。`map.geologyInputs` 核对界面点图层、界面字段、倾角和倾向；缺了就问。这两项都不生成画面或地层体。

设置里的外部能力显示 GDAL 开或关，以及专业权重未安装或已安装的名称。选择 `model.json` 后校验并写入 `var/models/igis-pro/model.json`。知识库、文档和审计收在「记录」里。
