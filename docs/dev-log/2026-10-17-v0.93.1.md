# V0.93.1

矢量：`map.erase` 从面上去掉另一个面，`map.union` 把重叠面合成一个面，`map.spatialJoin` 把面的字段抄到落在里面的点上。未声明坐标系时这三项拒绝。`map.quadtree` 用点建立四叉树。`map.aggregateGrid` 按格网计数，不保留原点。`map.chart` 按一个数值字段返回等宽直方图的个数。

`map.kernelDensity` 做高斯核密度。EPSG:4326 的带宽和格网边长按米，距离按球面，`_density` 是每平方公里的点数。未知坐标系按坐标单位。核在 3 倍带宽处截断，格网盖到这个范围。

路网由线图层在本机建图，交点按沿线位置切开。`map.snapToNetwork` 把点落到最近的边上，并在垂足处把该边切开。`map.networkDistance` 返回沿路最短距离的最小、最大和平均。`map.serviceArea` 返回给定距离内的路段；两端都走不满的边从两端各留一截。EPSG:4326 的距离是米，未知坐标系是坐标单位。没有转向限制。

`map.offsetLine` 用 shapely 的 `offset_curve` 生成平行线。正距离在线的左侧。地理坐标拒绝。已知投影坐标系按米。

栅格走 Python/GDAL 桥：`map.viewshed`、`map.rasterClip`、`map.polygonize`、`map.rasterize`、`map.zonal`、`map.resample`、`map.rasterIndex`、`map.focal`。指数只做 ndvi、ndwi、savi。邻域边长只做 3、5、7。栅格转面和面转栅格带上坐标系。`map.costCorridor` 在费用栅格上做 8 邻域最小费用路径，一步的费用是两端像元的均值乘步长；NoData 和不大于 0 的像元不可通行。`map.classify` 用同网格栅格和训练点做监督分类，在最小距离、最大似然和 kNN 上做分层交叉验证，输出类别栅格，并给出总体精度、Kappa 和混淆矩阵。

`map.hotspot` 算 Getis-Ord Gi*。给了路网时按沿路距离定邻居，否则按直线距离。`map.gwr` 做地理加权回归，用 Householder QR 求解，不给带宽时按 AICc 选择。`map.odFlow` 是双约束重力模型，阻隔函数为 `exp(−β·c)` 或 `c^(−β)`，费用可以是直线或路网；可以给定 β，或按目标平均费用标定。`map.kAnonymize` 用四叉树把点收成至少含 k 个点的区域，不输出原始点。`map.dpGrid` 对每个统计格的点数加拉普拉斯噪声后取整，且不小于 0；真实计数不输出，相同参数的重复请求返回同一份噪声。

`map.style` 增加 `colorField` 和 `labelField`。分类颜色由 MapLibre 按字段取值上色。样式里没有字形服务，注记由 `label-placement.js` 在屏幕像素上避让：点有 8 个候选位置，放不下的不画，也不压点符号。`map.exportMap` 把当前地图、注记、图例和比例尺画成一张 PNG。

桥的标准输入、输出和错误使用 UTF-8。进程适配器设置 `PYTHONIOENCODING=utf-8`，因为 Node 按 UTF-8 读管道。托管环境增加 shapely 2.2.0。
