# 2026-10-19 V0.97

一条对话是一份数据。它保存自己的记录、矢量图层、上传文件、栅格和三维场景。矢量图层在 `var/conversation-workspaces/<对话编号>/layers`。桌面聊天、地图接口、GDL 和 MCP 都打开这条对话的目录。地图和 GDL 在桌面里没有对话编号就拒绝。

删掉对话时，对话记录和工作区一起删掉。平面地图和三维都在工作区里。程序不再读取 `var/map-layers`。

地图只显示这条对话登记的图层。导入之后按这份名单重画。模型下一句读这条对话已经存下的来回记录。设置里的用户记忆仍是整份程序共用的偏好，不是这段上下文。

未改 `package.json` 与窗口模块的 `0.3.0`。
