# V0.93.3

语言规范的识别隔离。不新做分析算法。三维场景、爆炸图和地层体模型留到后面再定。

本地解析只执行整句没有歧义的指令：工具词明确，图层是已载入的名字或「当前图层」，需要距离时句中写了数字。句中没有距离就是缺槽，追问一句。200 不是空槽填充：早期测试句里的「200 米」「两百」被直接写进了 `local-intent.ts`、`pending-plan.ts` 和 `gis-route.ts`，那是测试反馈的遗留，不是距离规则。只有用户写出 200、两百或 200米时，距离才是 200。去掉工具词、已载入图层名、距离和虚词之后还剩字，整句原文交给模型，抽出的片段不是执行许可。已保存的对话不改写。

「帮我卓一下数据处理和缓冲，在这张图里」因此进模型，并带上当前选中图层。系统提示要求按错别字理解，只调用登记过的工具；「这张图」用选中图层；距离没写就问；对不上工具的说法就问。干净的「对这张图做 200 米缓冲」仍在本地执行。

思考里显示本机判断：不在本地执行、缺参数先问、或参数已齐。模型自己的推理可以附在后面。含坐标或几何的推理不显示。输入像坐标或几何时，发送前先提醒对话会保留原文、也可能随请求离开本机，请改用已载入图层。用户仍要发送就按原句走，不删原文，不把这些数字当成几何操作。

坐标系拒绝先返回原因。没有图层可重投影时停止，因为 `map.reproject` 只接受图层。目标 EPSG 还没给出时只追问，不重投影。重投影失败，或重投影后原运算再失败一次，停止并返回新的原因，不再重投影。同一工具、同一错误出现两次就停止，参数不改。

未改 `package.json` 和窗口模块版本 `0.3.0`。
