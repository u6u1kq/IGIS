# V0.91

六个工具接进现有登记表、别名、提示、适配器、`executeGisOperation`、操作记录和审计清单。没有另开 MCP 服务。

- `map.calculateField`：加减乘除、比较和 `if`。新字段不能是坐标字段。
- `map.join`：字段等值内连接。对不上的记录不进入结果图层。
- `map.rasterCast`、`map.rasterNoData`、`map.rasterSmooth`：本机 GDAL 桥。整型四舍五入。NoData 只写标记。平滑是 3×3 均值。
- `map.interpolate`：`gdal.Grid` 的 `invdist`、`nearest`、`linear`。留出点给出均方根误差和平均绝对误差。克里金会拒绝。

桥写出的文件名只保留 ASCII。`projectForModel` 保留 `rmse`、`mae`、`heldOut`。

核对：`npx --yes -p typescript tsc -p tsconfig.json --noEmit` 退出码 0。`v091-check`、`v087-capability-check`、`architecture-check` 和 `packages/llm-dispatch/src/self-check.ts` 退出码 0。`v091-check` 用托管 Python 3.11 的 GDAL 生成了整型、NoData、平滑和反距离插值栅格。浏览器未验证。未改 `package.json` 版本号。
