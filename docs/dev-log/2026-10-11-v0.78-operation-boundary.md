# 2026-10-11 V0.78 / V0.78-C 执行边界与修正（补记）

本文为 2026-10-11 补记。V0.78 与 V0.78-C 的实际开发早于本日志，内容依据当时的 TASK 文档与当前代码核对。

## 变更内容

- **统一执行边界**：`executeGisOperation` 先写 `running` 的 OperationRecord，校验后调用 SpatialService，结束写 `succeeded/failed`。五种空间操作 × 四个入口（chat/map/gdl/mcp）全部收口，operationId 覆盖不再是只有缓冲。记录含请求摘要、策略、副作用（新建图层/缓存键/知识条目）、审计 id、CRS 事实和来源（source/aiOrigin/translationUsed/requestSource）。
- **操作级回退**：`rollbackOperation` 按缓存键 → 知识条目 → 新建图层收回该操作自己的副作用；成功审计可选删，失败审计与来源账本保留。接入 `/api/conversations/rollback`，与轮级回退去重衔接。
- **本地 CRS 变换**：引入 proj4（BSD-2），仅 EPSG:4326 ↔ 3857。`crs-identity` 只认能证明的 EPSG 写法；`planCrsExecution` 统一策略——unknown/invalid 空间运算拒绝，4326/3857 之间本地对齐到工作 CRS 4326 后运算，结果变换回目标；调用方声明的 CRS 与图层冲突时拒绝，不改图层。缓存键纳入 CRS token，结果携带 `cacheKey` 与 CRS 事实。
- **AI 数据边界（V0.78-C）**：新包 `ai-boundary`（L0/L1/L2 数据级别、AI_SPATIAL_OPERATIONS、几何/文件键识别）与 `ai-translation`（projectForModel/releaseToModel/rejectModelToolCall/boundaryViolation）。适配器入口双向过闸：模型工具调用先拒绝违规，结果经白名单投影再释放给模型。
- **破坏性确认**：map.delete/clearAll/dropDatabase 需要运行时 `userConfirmed`；args 里的 confirm/userConfirmed 一律无效。
- **PPT 移除**：删除 `report-ppt.ts` 与 pptxgenjs 依赖，`/api/report/ppt` 不再存在。
