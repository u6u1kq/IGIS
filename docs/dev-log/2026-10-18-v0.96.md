# 2026-10-18 V0.96

发给模型的句子里，坐标换成「这些点」，绝对路径和 `.tif`、`.shp` 这类文件名换成「当前图层」。`ras-` 句柄留下。出现这些内容时不再把整段用户消息删掉。句子里的斜杠或省略号也不再把整句丢掉，路径片段换成「当前图层」，任务句子留下。坐标数字仍然不发出去。

`map.list` 只列出当前对话范围内的图层。范围为空时返回空列表，不把图层库里的旧图层交给模型。请求没有带范围时，用这张对话已经登记的图层，不把整个旧图层库接上。未载入的英文单词不再被当成图层名。
