# 2026-10-05 V0.7 PPT 生成、Igis GDL 与 GIS 内核底座

在 V0.61 上追加。没有 git 提交，没有改 git 配置。界面没有改版，也没有新页面：新控件只放进已有的导入对话框、图层右键菜单和报告对话框，另加两个弹窗（报告预览、统一错误）。旧路由、CLI、账本格式和 `var/spatial-audit` 的记录格式都保留，只做了追加。

## PPT 报告生成

- 模块名：`apps/cli/src/report-ppt.ts`（新），`apps/cli/src/desktop-api.ts`，`packages/llm-dispatch/src/text.ts`（新），`packages/llm-dispatch/src/session-config.ts`，`packages/llm-dispatch/src/local-mock.ts`，`apps/desktop/ui`。
- 变更内容：
  - `/api/report/ppt` 不再模拟，真实生成 PPTX。路由、侧栏按钮和表单字段都没变（两个素材复选框、模型下拉、任务 API Base/Key、输出单选）。表单只加了一个“附上当前地图快照”复选框，默认勾选。
  - 素材：
    - 图层名、几何类型、坐标系标签、要素数、字段名；
    - 勾选审计时加入 `var/spatial-audit` 最近 40 条（操作、输入图层、距离/单位/查询种类/属性筛选、输出文件名、时间、模型、结果）；
    - 勾选知识库时加入 RAG 前 5 条命中的标题和摘录。
  - 素材只包含名称、计数和参数，没有坐标；送模型前还会经过 `assertLlmPayload` 检查。
  - 文本生成走现有调用链 `requestLlmText`（内部是 `resolveLlmConnection`、`assertLlmPayload`、`postLlmJson`），没有新增 HTTP 客户端。
  - 配置的优先级：任务里填的模型、地址、密钥，然后是全局配置，最后是环境变量（`resolveTaskLlmConfig`）。local-mock 用 `createLocalReportMock`，结果确定，不访问网络。
  - 后端只组一份幻灯片模型（JSON）。幻灯片种类有：标题、表格、要点、图片、两栏。
  - 页序是：标题，数据概览，操作历史（勾选审计时才有），知识库发现（勾选知识库时才有），主要发现，地图快照，结论与下一步。表格每 8 行分一页。
  - PPTX 由 pptxgenjs 从这份模型渲染。字体只写 `Microsoft YaHei` 这个名称，不嵌入字体文件。
  - 网页预览读同一份 JSON，在报告预览弹窗里翻页。浏览器不解析 PPTX，也没有用预览库。
  - 每次运行都写一个新文件 `var/reports/igis-report-<yyyymmdd-HHMMSS>[-n].pptx`，重名时加序号，不覆盖旧文件。选“下载”时直接下载；选“预览”时先打开预览，预览里也能下载。
  - 地图快照在浏览器里截取：地图开启 `preserveDrawingBuffer`，画布缩到 1600 像素以内，转成 JPEG data URL 发给后端。只发图片，不发几何。
  - 所有失败都进统一错误弹窗，包括：
    - 模型错误、超时、没有密钥、网络不通；
    - 素材为空（返回 400）；
    - PPTX 写出失败；
    - 快照格式不对。
  - 服务进程不会因此崩溃。错误文字会先去掉密钥。
  - 每次生成（成功或失败）都追加一条 `operationType: "report"` 的空间审计记录，记录时间、模型、素材开关、输出方式、快照数、幻灯片页数和输出路径，不记密钥和坐标。
- 接口契约变更：
  - `POST /api/report/ppt` 请求体增加可选的 `mapSnapshots: [{dataUrl, width, height, caption}]`（最多 3 张，每张 6MB 以内，只收 PNG/JPEG），这个路由的请求体上限是 20MB。
  - 响应从 `{ok, simulated, message}` 改为 `{ok, message, fileName, downloadUrl, slideCount, output, deck}`。
  - 新增 `GET /api/report/file/<文件名>`：只读 `var/reports` 下符合 `igis-report-*.pptx` 命名的文件，按附件下载。
  - `SPATIAL_AUDIT_OPERATIONS` 增加 `report`。
- 未解决问题：
  - 远程 DeepSeek 只验证了失败路径（接口地址不可达时报错且不含密钥），没有用真实密钥跑过一次。
  - `npm audit` 报告 pptxgenjs 依赖的 image-size 1.2.1 有一个高危公告，未处理。
  - 字体只指定“Microsoft YaHei”，非 Windows 机器打开时会由 Office 替换字体。

## Igis GDL（地理描述语言）

- 模块名：`packages/gdl`（新，`@igis/gdl`），`apps/cli/src/gdl-http.ts`（新），`packages/llm-dispatch/src/registry.ts`，`packages/llm-dispatch/src/local-mock.ts`，`packages/shared-types/src/pipeline.ts`，`docs/gdl/grammar.md`（新），`apps/desktop/ui`。
- 变更内容：
  - 词法和语法分析都是手写的，没有用解析器生成器。语言包括：
    - 图层块：名称、几何类型、坐标系标签、带类型的字段；
    - 样式：填充、轮廓、宽度、透明度、显隐、顺序；
    - 要素：属性加类 WKT 几何字面量；
    - 运算：`BUFFER`/`INTERSECT`/`CLIP`；
    - `--` 注释。
  - 语法错误一次最多报 50 条，每条带行号和列号，在统一错误弹窗里列出。
  - 执行时先建图层，再通过图层库和内核算子跑运算；每步结果都是新图层。`STYLE ... order n` 会改图层库里的叠放顺序。
  - 图层可以导出为 GDL，写到 `var/gdl/<名称>-<时间>[-n].gdl`，不覆盖已有文件，同时让浏览器下载一份。导出和载入都记空间审计（`gdl-export`、`gdl-load`）。
  - 摘要模式把 `FEATURE` 行换成 `FEATURES n`，去掉属性值和几何。生成后再检查一次，发现几何字面量或坐标就拒绝输出。只有摘要可以写入知识库（走现有的 `store.add`）或交给模型。
  - 对话工具：
    - `gdl.run` 只接受引用已有图层的 `STYLE`/`BUFFER`/`INTERSECT`/`CLIP`。出现 `LAYER`、`FEATURE`、几何字面量、括号里的数字或两个相连的数字（像坐标）都会拒绝。
    - `gdl.describe` 返回图层摘要。
  - local-mock 在问题里含“GDL”时会调用这两个工具。
  - 界面：导入对话框里加了“Igis GDL（地理描述语言）”折叠区（文本框、`.gdl` 文件、写入知识库勾选、检查语法、载入GDL）。图层右键菜单加了“导出为GDL”和“GDL摘要写入知识库”。
  - 文档 `docs/gdl/grammar.md` 写明了语法，并注明它和 Graphisoft ArchiCAD 的 Geometric Description Language 同名但无关，没有沿用其语法。
- 接口契约变更：
  - 新增 `POST /api/gdl/parse {text}`、`/api/gdl/load {text, writeKnowledge}`、`/api/gdl/export {layerId}`、`/api/gdl/summary {layerId, writeKnowledge}`。
  - 失败时返回 `kind`（`gdl-syntax`、`gdl-guard`、`gdl-runtime`、`gis-core`、`failed`），并视情况带上 `errors[]`（行、列、消息）、`line`、`geometryIssues[]`，以及失败前已生成的 `layers[]`。
  - 新增对话工具 `gdl.run`、`gdl.describe`，`ToolPrefix` 增加 `gdl`。
  - `SPATIAL_AUDIT_OPERATIONS` 增加 `gdl-load`、`gdl-export`。
- 未解决问题：
  - 几何集合（GeometryCollection）要素无法导出为 GDL，会被省略，并提示省略了几个。
  - GDL 不做投影转换，`CRS` 只是标签。
  - 对话里用 local-mock 调 `gdl.run`/`gdl.describe` 的路径只用隔离脚本 `var/tmp/gdl-chat-smoke.mts` 验证过（图层库放在 var/tmp，跑完即删）：缓冲加样式生效，describe 返回摘要；直接提交几何字面量、`LAYER`/`GEOM`、裸坐标对都被拒绝。浏览器验收没有覆盖对话里的这条路径，因为切换全局模型为 local-mock 会改动用户的模型配置。

## 安全公告修复：image-size（pptxgenjs 传递依赖）

- 模块名：根 `package.json`（新增 `overrides`），`package-lock.json`，`config/licenses.lock.json`，`packages/license-check/src/record-v07.ts`（只改 image-size 一行数据）。
- 变更内容：
  - `npm audit` 报的是同一个包上的两条高危公告，都是畸形图片导致死循环的拒绝服务（CWE-835，CVSS 7.5）：
    - GHSA-5p2g-fcmc-qvqq（CVE-2025-71329），JXL 和 HEIF 解析器，受影响 `>=1.2.0 <=2.0.2`；
    - GHSA-w3rx-r6r6-pgpr（CVE-2025-71330），ICNS 解析器，受影响 `>=0.6.3 <=2.0.2`。
  - 两条公告的首个修复版都是 2.0.3，1.x 没有修复版，所以只能跨大版本。最终锁定 2.0.4：它和 2.0.3 只差 ICO 解析器多一处长度检查，属于额外加固。
